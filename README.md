# Blood Effects & Particle Control System for Godot

## Overview

This asset is a customizable blood particle effects system for Godot.

It provides an easy-to-use control system for testing and adjusting blood particle effects in real time. You can change blood speed, blood amount, emission mode, and camera view while running the scene.

The system is designed to be easy to integrate into FPS, TPS, action, horror, shooter, and other combat-based Godot projects.

---

## Features

- Real-time Blood Particle control
- Adjustable Blood Speed
- Adjustable Blood Amount
- Blood Amount up to 150x
- One-Burst emission mode
- Always-On emission mode
- Keyboard controls
- Reset settings
- Hide/Show control interface
- Adjustable camera position
- Camera zoom controls
- Easy-to-use in-game control panel

---

## Controls

### Blood Controls

| Key | Action |
|-----|--------|
| Q | Decrease Blood Speed |
| E | Increase Blood Speed |
| A | Decrease Blood Amount |
| D | Increase Blood Amount |
| SPACE | Play One Blood Burst |
| ENTER | Toggle Always-On Emitting |
| R | Reset Blood Settings |
| H | Hide / Show Controls |

### Camera Controls

| Input | Action |
|-------|--------|
| LMB + Mouse Move | Look / Rotate Camera |
| RMB + Mouse Move | Move Camera |
| Mouse Wheel Up | Move Camera Forward |
| Mouse Wheel Down | Move Camera Back |
| ESC | Release Mouse |

---

## Blood Amount

Press and hold **A / D** to decrease or increase the Blood Amount.

The Blood Amount can be adjusted up to **150x**.

---

## Emission Modes

### One Burst

Press **SPACE** to emit one blood particle burst.

### Always On

Press **ENTER** or use the Emitting control to enable Always-On emission.

Press **ENTER** again to turn Always-On emission off.

---

## Reset

Press **R** to reset the blood settings to their original values.

The reset restores:

- Blood Speed
- Blood Amount
- Emission Mode
- Particle emission state

---

## Hide Controls

Press **H** to hide or show the control interface.

This is useful when you want a cleaner view of the blood effect while testing.

---

## Customization

The following values can be adjusted from the script:

- Mouse sensitivity
- Camera movement sensitivity
- Camera zoom sensitivity
- Blood speed
- Blood amount
- Speed adjustment step
- Amount adjustment step

---

## Installation

1. Import the asset into your Godot project.
2. Open the included scene.
3. Make sure the required particle nodes are present.
4. Attach/use the provided script.
5. Run the scene.
6. Use the keyboard controls to test and customize the blood effect.
